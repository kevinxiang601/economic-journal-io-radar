# 管理学模式：UTD24 全覆盖、按研究主线精选

## 范围与输出

仅限 `management-journals.json` 列出的 UTD24。以UT Dallas官方清单核对集合；期刊官网变更时重新发现入口，不用失效旧网址判定零新增。全24刊均扫描Crossref的创建/在线出版窗口，并检查官方最新期/在线优先目录及独立结构化渠道；MS、Marketing Science、MSOM、POM、JM、JMR只是用户举例，不是上限。ISR、MISQ、Organization Science、SMJ、JCR、JOM等应按题目深入，OR/IJOC只找符合研究主线的传统博弈/实证，不能被纯算法内容淹没。其余会计、金融、组织期刊也扫描，按具体贡献取舍。

默认45天滚动窗口加最新卷期/全部活跃在线优先页面的遗漏核查；首次正式上线时收录，DOI创建或分配卷期不是重复新增。第一次管理学测试也使用45天窗口，超窗候选不为了凑数加入。24刊之外的论文、会议、SSRN/NBER不进入管理学成品；可作发现线索。经济学的NBER仍只在经济学周执行。

管理学每期总共最多30篇（正文与观察合计），目标约25–30但不设最低篇数。先做相关性与方法筛选，再用时间精简：候选过多时优先近期、必要时收窄主要窗口，但要回看45天候选，不能因略早就漏掉明显更相关的论文。按相关性、具体贡献、方法可借鉴性优先，时间只作次级排序/同档取舍。不可用最近但低相关论文替换高相关稍早论文；不得绕过上限再以观察/附件补齐。未介绍的合格候选可在内部续做记录中保留，但不能标为已收录。经济学沿用相关性优先，**不设论文总数上限**。

成品目录与论文目录读 `configuration.md`；文件名 `管理学顶刊速览-YYYY-MM-DD.md`，日期文件夹放验证成功的论文。先读管理学、经济学全部历史、累计记录及已下载文件，跨版本、跨系列去重。同一研究在两类周刊之间也不重复。首轮之前没有管理学基线，不表示已在经济学介绍过的论文是新增。

使用 `python3 scripts/collect_management.py --as-of YYYY-MM-DD --lookback 45 --openalex --history-dir <经济学历史目录> --history-dir <管理学历史目录> --output /tmp/management-candidates.json` 发现候选；可重复传入额外历史目录。保存完整候选池且不按关键词直接排除。仅题名命中的重复提示还要核对作者与跨版本关系，不能直接丢弃同名不同研究。官方单篇目录与注册集合差异逐项复核，必要时用精确标题/作者公开稿补漏；不要将在线优先摘要预览的一句话或出版社编辑推荐当作者完整摘要。

## 研究与方法优先级

主线为平台、AI、IO与其和供应链/营销的实质交叉。传统供应/生产网络低优先级，只有具体模型或识别启发才保留；环境沿用精选次级门槛和（环境）标记。保留已获用户认可的跨领域需求/方法视角贡献，不能只看行业标签。纯优化、交通运输运行、算法性能论文默认排除。

沿用评分v2的35/45/10/10、星级与相关性硬上限，但管理学方法适配有以下专门要求：

- 传统均衡博弈、合同/信息/机制设计：优先，按策略选择、信息、激励、均衡和比较静态的实质贡献评38–45。不要将任何数学最优化称为博弈。
- 实证优先可理解可复用的DID、IV、RD/RDD、DDD、随机现场/实验室实验、清楚的事件研究和常规structural IO。有效识别与经济问题贡献决定高分，方法熟悉本身不证明有效。
- 算法博弈、计算复杂性、近似比、遗憾界、均衡求解算法或多智能体学习算法为主要贡献：方法适配最多19、通常排除。AI定价若研究传统企业均衡或真实平台行为仍可入选，不能因题目带“算法”机械排除；关键是研究贡献，而非关键词。
- 高度新颖的估计量、深度结构网络、因果森林或ML推断为主要贡献，且需要掌握陌生方法才能借用：方法适配最多27，通常不进四五星；只有明确经济视角贡献才精选三星。常规DID/RDD/实验使用ML作辅助度量不自动受此上限，须说明它是否承担主要识别。
- 传统库存或调度问题增加普通参数，不因有均衡就高分。创新并非“多一个变量”，须看其是否改变激励、预测、边界或量级。

## 每篇新增研究评价（两类速览共用）

使用用户指定的 `research-method-distiller`（可用时读取SKILL.md及相关研究价值/理论/实证指引）。在直白解释之后、官方来源之前新增一段 `- 研究评价：`，一般3–5句、约120–220字，具体可核查、少术语；不复制直白解释。

- 理论：原文实际对照的基准/通常认识是什么 → 新加入或内生化的关键变量、信息、时序或制度是什么 → 谁的激励如何改变 → 最有价值/反直觉结果为何出现。没有明确基准就说明作者分析的关键机制，不能捏造“传统理论一定认为”。若贡献来自新刻画/边界而不是新变量，按真实贡献评价。
- 实证：既有认识缺什么 → 新数据、外生变异、比较或测量边界如何补上 → 最有创意的发现或识别选择 → 能借鉴什么具体研究设计或经济视角。区分因果证据、机制解释和自己的延伸；方法复杂不等于价值高。
- 读摘要用于初筛，核心评价要追读可取得的引言、模型/识别与结果段。只取得摘要时，评价只能限于摘要明确支持的内容；必要时用一个短语标明“摘要可确认的增量是…”，不编命题、参数、识别或作者没有给出的对照。不要反复加泛泛免责声明。反直觉不是必要条件；重要量级、机制区分和识别改进也有价值。

## 成品与验证

两类报告开头只放“运行窗口”和“发现与筛选”，后者简短给候选/历史重复/主清单数量；保留日期标题。不写方法汇报、评分口径段、覆盖表、失败列表或工作总结。各篇保留完整逐句中文Abstract、评分分项、三句直白解释、研究评价、最后官方来源；下载只加（已下载），不建清单。末尾可有真正有价值的观察区，最后累计已收录清单。内部保留24刊检查点和差异，不在成品堆叠。

交付前用 `audit_digest.py` 检查：限定期刊、评分和方法类别、环境门槛、跨期重复、摘要是否完整、研究评价是否有原文依据、来源在最后、标记与实际PDF一致。确定性脚本不能证明摘要完整或研究判断正确，另逐篇人工复核摘要边界和评价事实。下载门槛跨本期全部主清单统一计算：4/5星≤10下载两档，否则只下载5星，验证PDF与题名。没有合格条目也输出简短零新增稿与累计清单。
